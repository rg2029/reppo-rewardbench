# Reppo RewardBench: report viewer

Load a locally generated `report.json` to inspect which judging methods were evaluated, how many tasks completed, and their task-macro ranking accuracy. The file is read in your browser. It is not sent to Reppo or to this Space's server.

A first two-task coding-agent feasibility result is documented in [GitHub](https://github.com/rg2029/reppo-rewardbench/blob/main/results/CODING_AGENT_FEASIBILITY_2026-11-02.md): Reppo tied on one task and incorrectly ranked the other. The viewer does not run model inference or host a validated benchmark leaderboard. The published dataset is an arithmetic format check; the research program is comparing judgments with independently checked agent outcomes.

Method, provenance and the current evidence are documented in the [GitHub repository](https://github.com/rg2029/reppo-rewardbench). The paper remains a working manuscript while matched results are collected.
